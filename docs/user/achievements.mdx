Achievements and experience points (XP) are optional recognition features. When a workspace admin enables them, Hephaestus assigns XP and achievements for selected activity in connected repositories. These features do not affect practice feedback.

## Experience points

Actions such as creating a pull request, reviewing code, or closing an issue can earn XP. The exact scoring depends on the workspace configuration.

- Your profile shows which activities contributed to your XP.
- When the [leaderboard](./leaderboard) is enabled, its score is based on this activity.

## Achievements

Achievements mark activity milestones. A workspace can use the standard achievement package or configure its own.

### Categories

- **Pull requests:** merging pull requests or merge requests.
- **Commits:** authoring commits.
- **Communication:** approving, requesting changes, or commenting in code reviews.
- **Issues:** opening and closing issues.
- **Milestones:** broader events, such as completing a first tracked action.

### Rarities

An achievement can be labelled **Common**, **Uncommon**, **Rare**, **Epic**, **Legendary**, or **Mythic**. The label reflects the threshold configured for that achievement; it does not assess the quality of the work.

### Hidden achievements

Some achievements remain hidden until they are unlocked. For example, the standard achievement package includes the hidden *Night Owl* achievement.

## Check your progress

Open your profile or the **Achievements** page to see:

- recently unlocked achievements
- progress towards the next rank
- available achievement paths and their next thresholds
