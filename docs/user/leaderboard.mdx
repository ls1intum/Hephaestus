Hephaestus includes an optional weekly leaderboard that tracks review activity across your workspace. Workspace admins decide whether it is enabled. Scores are recalculated continuously, so the table reflects your contributions in near real time.

## Accessing the leaderboard

Sign in and select a workspace. When that workspace has the leaderboard enabled, it is the workspace home page.

## Reading the overview card

The overview card summarises your position on the current leaderboard:

- Current rank within the selected leaderboard.
- Time remaining until the week resets.
- When leagues are also enabled, your projected **league point** adjustment, current tier, and progress towards the next tier.

![Leaderboard overview card](./img/leaderboard/leaderboard-overview.png)

:::tip Jump to your row
Selecting your rank in the overview card scrolls the table to highlight your entry.
:::

## Table columns and reviewer drawer

The leaderboard table includes rank, contributor, leaderboard score, and activity summary. Selecting any reviewer opens a detailed drawer that shows:

- Pull requests or merge requests reviewed that week, with links to the source platform.
- Key statistics such as additions, deletions, and review sentiment.
- A **Copy** action that formats review highlights for sharing in standups or retrospectives.

![Leaderboard pull request overview](./img/leaderboard/leaderboard-pr-overview.png)

## Exploring previous weeks and teams

- Use the **time period** dropdown to switch between the current and previous weeks (the last four are stored by default).
- Apply the **team filter** to view review activity within a specific team. Your personal rank only appears when the selected team includes you.
- Filter by **labels** when your organisation tags pull requests per exercise or milestone.

![Leaderboard filters](./img/leaderboard/leaderboard-filter.png)

:::note Optional league scoring
When a workspace admin enables leagues, weekly points feed into the Elo-inspired league system. League information is hidden when the feature is off.
:::

## Recognition and notifications

A workspace admin can configure a weekly Slack digest for a selected channel and team. The admin chooses the day, time, timezone, and destination under **Admin → Integrations → Slack**. Hephaestus does not send a leaderboard digest unless this option is enabled.
