The admin trace, the developer's own reviews and the scan report no longer say that a partial review stopped or did not finish. A partial review can run to the end and still leave a practice without a result, so these views now state only what its results cover. The trace names the recorded reason, which still says when a review ran out of time, and marks the Results stage. The developer's reviews show *Partial* instead of *Did not finish*. A review that failed or was cancelled still says that it stopped.
