The API reference and the Review screen now describe the tier ladder as what it is — how much
the system may do on its own — instead of how loud it is. The API reference previously described a
practice's tier as "how loudly the workspace runs this practice" and the reach setting as something that
"cannot make a quiet practice speak", which read as a volume control and left it unclear that Propose
still runs the review and still records every observation.
