Practice scripts can decide from captured records, ask a review model, or call assigned decision, embedding and reranking models. Every script uses the same result contract and evidence checks. A script failure creates no claim about the work and never falls back to the built-in script. Direct model calls follow the developer's AI choice and the review's stricter model tier. Operators can inspect script execution, model use and cost for each practice.
