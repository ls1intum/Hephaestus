Fixes in the admin Practice reviews. Observations sorted **Most actionable first** no longer repeat a day heading each time the day comes back; each row names its day instead. Closing a trace and the sheet over it at once, from the path or by pressing outside, no longer leaves the browser's Back to open them again. A review sheet left open reads the review's counts again when the review finishes, and the count behind a tab is asked for again after a failed read instead of staying hidden. A duration reads the same in the trace, the sheets and the cards, and the trace marks the section its bottleneck line names. A backfilled review is **Backfilled** wherever the admin names how a review came about.
