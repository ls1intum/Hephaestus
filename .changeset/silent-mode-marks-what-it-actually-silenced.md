Silent Mode now marks the piece of coaching it actually stopped. When an instance is silenced, the mentor turn's queued feedback is recorded as withheld by Silent Mode — but only for a finding the turn was allowed to raise in the first place. Feedback about work whose evidence is no longer readable, or whose practice has been re-configured since the review ran, stays queued instead of being retired under a reason that was never the one that stopped it, and it can still be raised once it is readable again.
