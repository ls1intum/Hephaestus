The application API can now answer where a developer stands in each practice area: the current standing and the guidance behind it, how the area has developed across recently reviewed work, which kinds of work the feedback came from, a filterable list of that feedback, and the complete review moments that produced it. It also accepts marking a delivered piece of feedback as helpful, unhelpful, or incorrect, with an optional explanatory comment. Every one of these answers only for the signed-in developer. There is no way to request another person's standing. Nothing changes in the app yet; the screens that read this arrive separately.
