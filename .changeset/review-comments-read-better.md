Review comments read better and land where the code is. A comment used to announce its own count twice — once in the opening line and again in the heading below it — and a strength ran its observation and its next step together into a single unpunctuated sentence. The footer carried the run's duration, which tells the developer reading it nothing. And a defect found by opening the file was quoted from the file rather than the change, so the note that belonged beside the line arrived as a paragraph at the bottom instead; reviews now quote the change for anything the change introduced.
