A review that reads the evidence and genuinely cannot call it now says "Inconclusive" rather than the more obscure wording it used before, and a review that says a practice does not apply to a change now has to say what makes it not apply — naming what the practice looks for and the fact about that change which rules it out. "Not applicable" was previously the only answer that cost nothing to give, so it was collecting cases that were really "we could not tell", which read back as "there was nothing to see here" in a developer's record. Expect fewer not-applicable results and more inconclusive ones; the totals stay the same, but each is now saying what it means.
