"hephaestus": minor

Heph now keeps one conversation with you in each workspace. The Heph page and the Heph panel show all of it, with a Slack marker on the messages written in Slack. Your Slack direct message shows what you asked there and Heph's answers. You can reply to any message in a thread.

Heph answers where you asked. A question from the app gets its answer only in the app. You can send another message while Heph answers and delete your own messages. You stop an answer in the app, also an answer that Heph writes in Slack. You rate an answer as **Helpful** or **Not helpful**, also in a Slack thread. Heph does not say that it is busy and does not need time to get ready. **New chat**, the chat history list and editing a sent message are gone. The upgrade deletes earlier Heph chat history.

Heph can point to a result or a problem in your work, and it can show you feedback that a review prepared for your conversation. That feedback counts as delivered only when Heph shows it in an answer that you can see. Hephaestus does not post an answer to Slack a second time. If an answer does not fully reach Slack, the app shows "Not fully delivered to Slack. The full answer is here."

Heph can now read the code of the repositories that your workspace monitors, with their history and changes. It reads them at a branch, a commit, a pull request or a merge request. It can search the files and compare two versions, and it names the commit that it read. Heph only reads: it cannot run, build or change your code.

**Operators:** Stop every role before you upgrade. The upgrade drops the Heph chat tables and deletes earlier Heph chat history. Back up the database and keep the release lock of the previous release for a restore. Update the Slack app from the manifest template, reinstall it, and select **Reconnect Slack** in each workspace that uses it. Rename `HEPHAESTUS_RATE_LIMIT_MENTOR_CHAT_*` to `HEPHAESTUS_RATE_LIMIT_MENTOR_TURNS_*`. Remove the Traefik sticky-cookie labels and the removed `hephaestus.mentor.*` settings. The **Internet access** switch of the Heph model assignment is removed, and Heph has no internet access. If you pin a custom agent image, rebuild it for runtime contract 8. Each worker starts one Heph host container, and the recommended single host has 24 GB of memory. Heph reads your work and code in a short-lived sandbox on the worker, with no network and no credentials. Each worker keeps 2 empty sandboxes ready and starts one for each running answer, with 1 CPU and 1 GiB of memory each. The worker needs Docker for these sandboxes. Heph reads code only where Git mirrors are enabled. Heph refuses a model with a context window below 32,768 tokens or an output limit below 4,096 tokens. The migration guide lists the removed settings, the new settings and the changed metrics.
